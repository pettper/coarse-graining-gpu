# [coarse-graining-gpu]

**A small GPU-accelerated coarse graining library**

Instructions:
  1. Clone the repo
  2. pip install -U "jax[cuda12]" (Or other cuda version)
  3. pip install warp-lang
  4. pip install -e ./pyproject.toml (Run in your virtual environment to get correct package dependencies.)
Usage:
  Main class is found in *coarse_graining_main.py*
